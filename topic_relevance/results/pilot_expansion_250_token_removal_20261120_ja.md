# 250ブロック：トークン除去防御の応答実験

## 実施内容

250ブロックそれぞれの文脈A/BとプローブA/Bを交差させ、4組ずつ、
合計**1,000入力**を作成した。各入力について防御なしと防御ありを実行し、
**2,000応答**を保存した。AA/BBは作成時の「関連意図」、AB/BAは
「非関連意図」として各500入力だが、人手で関連度を確認したラベルではない。

- モデル：Qwen2.5-3B-Instruct、4-bit NF4
- デコード：`do_sample=False`、最大384生成トークン
- 入力長：事前検査145〜183トークン、512上限内
- 検知器：固定済みattention detector checkpoint
- 判定：分類器の2クラスlogitsに幅5の平均フィルタを適用し、argmaxでトークン判定。
  チェックポイントの通常の0.5確率閾値は使わない。
- 防御：陽性トークンIDを除去してデコード。マーカー置換は行わない。
- 入力形式：従来条件との整合のため、タスク指示から3つの制約文を除去し、
  JSON形式指示は保持した。クリーン文脈末尾に既定のfake-completion
  ラッパーとプローブ本文を挿入した。

攻撃成功判定およびタスク正答判定は行っていない。期待回答とタスクgoldは
後続の別モデル判定に使えるようCSVに保持した。

## トークン検知率

主指標を**プローブ本文内のトークン検知率**とする。領域境界をまたぐ
トークンは分母・分子に含めない。参考としてラッパー＋プローブ全体の率も示す。

| 対象 | 検知トークン / 対象トークン | 検知率 |
|---|---:|---:|
| プローブ本文 | 5,485 / 16,312 | 33.63% |
| ラッパー＋プローブ | 19,485 / 30,312 | 64.28% |

| 作成時の関連度意図 | プローブ本文 | ラッパー＋プローブ |
|---|---:|---:|
| 関連意図（500入力） | 2,734 / 8,156 = 33.52% | 9,734 / 15,156 = 64.23% |
| 非関連意図（500入力） | 2,751 / 8,156 = 33.73% | 9,751 / 15,156 = 64.34% |

これは候補作成時の意図ラベル別集計であり、人手確認済み関連度に基づく比較ではない。
防御なし条件では検知を実施していないため、検知率欄は空欄である。

## 出力上限

2,000応答中1件が384トークン上限に到達し、EOSで終了しなかった。
該当入力は`pilot_435__context_A_probe_A`の防御なし条件。CSVには生成された
文章と上限到達フラグをそのまま記録しており、この1件は途中で切れている可能性がある。
残り1,999件は上限到達なし。
