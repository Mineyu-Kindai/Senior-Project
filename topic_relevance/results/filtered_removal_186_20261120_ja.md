# 残り186ブロック：連続陽性長フィルタ付きトークン除去

## 実験条件

前回の開発用64ブロックを除いた`pilot_265`〜`pilot_450`を対象とした。
186ブロック×4組の**744入力**それぞれに、防御あり・なしの応答を用意した
（計1,488応答）。前回の64ブロックと合わせると250ブロック、1,000入力、
2,000応答である。

防御設定は前回と同じ、2クラスlogitsの幅5の平均、攻撃−正常logit差
`> 0.0`で陽性、連続6トークン以上の陽性のみ除去。モデルは
Qwen2.5-3B-Instruct、CUDA 4-bit NF4、`do_sample=False`、入力上限512、
出力上限384。モデルrevision、tokenizer、chat template、ライブラリ、
設定などが前回64ブロックの実行条件と一致することを確認した。
タスク指示は前回同様、3つの制約文を除去しJSON形式指示を保持した。

250ブロック実験の保存済みスコアに最新の判定・除去ルールを適用した。
Attention抽出と分類器推論は再実行していない。トークンID・オフセットを
照合し、トークン除去後のデコードが文字オフセットによる除去と全744入力で
一致することを確認した。応答は入力と生成条件を照合し、防御なし744件、
防御あり74件を再利用し、防御あり670件を新規生成した。
元の250ブロック実験ログには当時のchat template自体が記録されていないため、
その時点のtemplateの一致は直接検証できない。

## 検知・除去結果

陽性判定は連続長フィルタ前、除去はフィルタ後。境界をまたぐトークンは
プローブとラッパーの各率から除外し、分子・分母を全入力で合算した。
防御なしでは検知を行っていない。

| 対象 | 陽性判定 | 実際に除去 |
|---|---:|---:|
| プローブ本文 | 4,270 / 12,790 = **33.39%** | 4,224 / 12,790 = **33.03%** |
| 共通ラッパー | 10,416 / 10,416 = 100.00% | 10,416 / 10,416 = 100.00% |
| ラッパー＋プローブ | 14,686 / 23,206 = 63.29% | 14,640 / 23,206 = 63.09% |

| 作成時の関連度意図 | 入力数 | プローブ本文の陽性判定率 | プローブ本文の除去率 |
|---|---:|---:|---:|
| 関連意図 | 372 | 2,117 / 6,395 = 33.10% | 2,096 / 6,395 = 32.78% |
| 非関連意図 | 372 | 2,153 / 6,395 = 33.67% | 2,128 / 6,395 = 33.28% |

攻撃入力に含まれる正常本文の除去文字数は32,412 / 146,758 = **22.09%**。
前回64ブロックの6.35%より高い。同じ本文が複数の攻撃入力に現れるため、
分母は入力ごとの文字数の合計であり、clean-only入力での誤検知率ではない。
正常タスクへの影響は後の正答判定が必要。

参考として250ブロック全体のプローブ本文の陽性判定は5,485 / 16,312 =
33.63%、除去は5,439 / 16,312 = 33.34%。開発用64ブロックを含む集計である。

## 制約と確認事項

- 今回の186ブロックは閾値・連続長の選択には使っていない。ただし以前の
  250ブロック実験で対象データと旧方式の結果を扱っており、完全に未観測の
  独立テストデータとはいえない。
- 関連／非関連は作成時の意図で、人手確認済みではない。
- 攻撃成功・正常タスク正答は採点していない。検知・除去率だけで攻撃抑止や
  タスク正答を判断できない。
- 出力上限到達は1件。`pilot_435__context_A_probe_A`の防御なし応答で、
  前回実験からの再利用である。出力が途中で切れている可能性がある。
- 全CSV行を保存スコア・生成ログから再構成し、各集計、ハッシュ、前回64
  ブロックとの重複がないことを確認した。
