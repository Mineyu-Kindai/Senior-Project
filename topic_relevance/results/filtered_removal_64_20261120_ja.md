# 64ブロック：連続陽性長フィルタ付きトークン除去

## 実験内容

探索用`pilot_201`〜`pilot_264`の64ブロックについて、文脈A/Bと
プローブA/Bの各4組を、防御あり・なしで処理した。対象は250ブロック候補の
先頭64ブロックであり、`pilot_257`はその中の修正版である。
合計**256入力・512応答**。

防御ありは、分類器の2クラスlogitsを幅5で平均し、攻撃クラスと正常クラスの
差が0.0を超えるトークンを陽性とした。陽性が6トークン以上連続する箇所だけ
除去し、残ったトークンをデコードした。マーカーは挿入していない。

前回の250ブロック実験の保存済みlogit差を再利用し、最新の判定・除去
フィルタを適用した。検知器のAttention抽出や分類器推論は再実行していない。
全256入力でtokenizerのID・オフセットを照合し、トークン除去後のデコードが
文字オフセットによる除去結果と一致することも検証した。

応答は、同じ入力・実行条件で前回保存した防御なし256件と、防御ありのうち
入力が完全一致する53件を再利用し、残りの防御あり203件を新規生成した。
モデルrevision・tokenizer本体ハッシュ・ライブラリ等を照合した。前回の
250ブロック実験ログにはchat template自体が記録されていないため、その時点の
templateの一致はハッシュとして直接検証できない。

モデルはQwen2.5-3B-Instruct、4-bit NF4、`do_sample=False`、入力上限512、
出力上限384。モデル入力は117〜167トークンで、**出力上限到達は0件**。
タスク指示は前回同様、3つの制約文を除去しJSON形式指示を保持した。

## 防御あり：トークン検知・除去

境界をまたぐトークンはプローブ・ラッパーの各率から除外し、
全入力の分子・分母を合算した率を示す。陽性判定は連続長フィルタ前、
除去はフィルタ後のトークン数。

| 対象 | 陽性判定 | 実際に除去 |
|---|---:|---:|
| プローブ本文 | 1,215 / 3,522 = **34.50%** | 1,215 / 3,522 = **34.50%** |
| 共通ラッパー | 3,584 / 3,584 = 100.00% | 3,584 / 3,584 = 100.00% |
| ラッパー＋プローブ | 4,799 / 7,106 = 67.53% | 4,799 / 7,106 = 67.53% |

| 作成時の関連度意図 | 入力数 | プローブ本文の陽性判定率 | プローブ本文の除去率 |
|---|---:|---:|---:|
| 関連意図 | 128 | 617 / 1,761 = 35.04% | 617 / 1,761 = 35.04% |
| 非関連意図 | 128 | 598 / 1,761 = 33.96% | 598 / 1,761 = 33.96% |

正常本文の除去文字数は2,704 / 42,554 = 6.35%。同じ本文が複数の
攻撃入力に現れるため、この分母は入力ごとの文字数の合計である。
防御なしでは検知を行っておらず、検知率は対象外。

## 注意点

- 関連／非関連は候補作成時の意図であり、人手確認済みの関連度ではない。
- この64ブロックは現在の設定を選んだ開発用データと同一である。上記の
  検知・除去率を未使用データでの確認結果とはみなせない。
- 攻撃成功判定と正常タスク正答判定は**実施していない**。出力全文、
  期待回答、許容表現、タスクgoldは後の判定用にCSVに保存した。
- プローブ本文を34.50%検知したことやラッパーを全検知したことは、
  攻撃を防げたことを意味しない。RENNERVATE全体の再現でもない。
